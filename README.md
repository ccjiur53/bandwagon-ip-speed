## 什么是搬瓦工测试IP？为什么购买前要先测？

**搬瓦工测试IP（Test IP）**，是搬瓦工（BandwagonHost）各数据中心提供的公开IP地址，专门用于购买前的网络质量测试。通过对这些IP执行 ping 或下载测速文件，用户可以直接测量本地到该机房的延迟（latency）和下载速度，从而判断某个机房是否适合自己。

简单说：**不同地区的用户，不同运营商（电信/联通/移动），对同一机房的体验差异很大。** 没有一个机房对所有人都最优，测试是选机房最直接的方法。

## 怎么用测试IP测速？3种方法任选

拿到 IP 之后，用哪种方法测取决于你的需求。

**方法一：本地 ping（最简单）**

Windows 用户打开 PowerShell 或命令提示符，输入：


ping 93.179.124.204


将 IP 替换成你想测试的机房。结果会显示延迟（ms）和丢包率。Mac/Linux 用户直接在终端执行同样命令即可。

**方法二：在线全国 ping 测试**

打开 [http://ping.chinaz.com/](http://ping.chinaz.com/)，在输入框粘贴测试IP，就能看到全国各省市、各运营商到该 IP 的延迟分布图。这是最推荐的方式，一次性看清楚电信/联通/移动三网的真实延迟，而不只是你家宽带的数据。

**方法三：下载测速文件**

部分机房提供下载测速文件，直接点击文件链接下载，观察下载速度即可。比如洛杉矶 DC2 机房提供 100MB/500MB/1000MB 三种大小的测试文件：

- 100 MB：`http://23.252.96.201/100mb.bin`
- 500 MB：`http://23.252.96.201/500mb.bin`
- 1000 MB：`http://23.252.96.201/1000mb.bin`

下载速度直接反映机房带宽对你的实际可用性。

## FAQ 常见问题

**Q：搬瓦工测试IP免费用吗？谁都可以 ping 吗？**

可以。这些测试IP是公开信息，任何人都可以用来测试延迟，不需要账号也不需要付费。

**Q：ping 延迟低就代表速度快吗？**

不完全是。ping 测的是 ICMP 延迟，实际下载速度还涉及带宽、拥塞等因素。延迟低是好的信号，但建议配合下载测速文件一起验证。

**Q：DC3/DC4 机房的测试IP还能用吗？**

DC3 CN2 和 DC4 MCOM 机房已下线，测试IP在技术上可能还能 ping 通，但对应套餐已无法购买，仅供历史参考。

**Q：CN2 GIA-E 套餐可以切换到香港机房吗？**

不能。香港机房和东京 CN2 GIA 机房属于独立套餐体系，不包含在 CN2 GIA-E 套餐的迁移范围内。如果需要香港节点，需要单独购买香港套餐。
